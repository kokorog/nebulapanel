# NebulaPanel Documentation Website

Public, documentation-only website for NebulaPanel. The commercial FiveM resource is
not stored in this repository and is distributed exclusively through Tebex.

## Preview locally

Open `index.html` directly, or run any static HTTP server in this directory.

## Publish with GitHub Pages

1. Create a new public repository for this folder only.
2. Replace the placeholders in `index.html`:
   - `SUPPORT_URL`
3. Push this directory to the repository's default branch.
4. In GitHub, open **Settings → Pages → Build and deployment** and select
   **GitHub Actions**.
5. The included workflow publishes the site automatically.

Do not copy `nebula-core`, `nebula-web`, release archives, source maps, production
configuration, or customer data into this repository.
